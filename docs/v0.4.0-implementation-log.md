## 补充约束（2026-09-04）

1. ZIP 网络连接约 10 秒、数据停滞约 30 秒，需实际弱网/VPN 验证。
2. Ed25519 使用 key_id + TrustedKeyring；仅可信应用版本预置新公钥，未知远程公钥不得自动受信。
3. 应用更新签名不等于 Windows Authenticode，本轮不要求商业代码签名。
4. Release 仅用于发现，验签 manifest 是权威；tag、manifest、asset 版本一致。
5. 重定向仅 HTTPS、有界且限实证验证的 GitHub 官方资产域名。
6. 按卷计算 ZIP、候选目录、旧版本 backup 和安全余量。
7. 动效 P95 ≤ 20ms、P99 ≤ 33ms，无动效导致的 >50ms stall；>100ms 为严重回归。
8. CHECK_ONLY / DOWNLOAD_AND_VERIFY / AUTO_INSTALL 分级，源码与验证版保留检查能力。
9. Snapshot 64 MiB/窗口，按实际 device-pixel backing size 计费，包括 DPR²。
10. Phase 9 分 Discovery、Signature、Download/Staging、Updater/Rollback、UI/Busy Coordination 独立提交。
