# v0.4.0 实施记录（未发布）

仅在 develop 开发；不修改稳定分支、旧标签和旧发布物，不 push/merge/发布，不自动生成正式私钥。

## 补充约束（2026-09-04）

1. ZIP 网络连接约 10 秒、数据停滞约 30 秒，需实际弱网/VPN 验证。
2. Ed25519 使用 key_id + TrustedKeyring；仅可信应用版本预置新公钥，未知远程公钥不得自动受信。
3. 应用更新签名不等于 Windows Authenticode，本轮不要求商业代码签名。
4. Release 仅用于发现，验签 manifest 是权威；tag、manifest、asset 版本一致。
5. 重定向仅 HTTPS、有界且限实证验证的 GitHub 官方资产域名。
6. 按卷计算 ZIP、候选目录、旧版本 backup 和安全余量。
7. 动效 P95 ≤ 20ms、P99 ≤ 33ms，无动效导致的 >50ms stall；>100ms 为严重回归。
8. CHECK_ONLY / DOWNLOAD_AND_VERIFY / AUTO_INSTALL 分级，源码与验证版保留检查能力。
9. Snapshot 64 MiB/窗口，按实际 device-pixel backing size 计费，包括 DPR²。
10. Phase 9 分 Discovery、Signature、Download/Staging、Updater/Rollback、UI/Busy Coordination 独立提交。

## Phase 9D — External updater and rollback

- Added a no-Qt, windowed external updater entry point. It independently verifies the embedded Ed25519 trust root, raw manifest signature, version/protocol, package length and SHA256 before extraction.
- Added strict ZIP validation for traversal, absolute/drive/ADS/device names, case-folding duplicates, links, signed extracted size, exact ownership hashes and critical executables.
- Added same-volume candidate/backup switching with an atomic transaction journal, exclusive transaction lock, process-handle wait, isolated offline self-test, startup health handshake, rollback and idempotent interrupted-transaction recovery.
- The production trusted-key mapping intentionally remains empty. Source and validation builds therefore cannot invoke production installation before the separately approved key ceremony.
  - 完整回归：223 passed（17.74 秒）。独立 PyInstaller 验证生成 11.60 MiB windowed EXE（PE subsystem 2），归档中 PySide6/Qt 条目为 0；无参数运行安全退出码为 2。

- Phase 9E UI/Busy Coordination 完成：设置 schema 4 新增默认开启的自动检查并在首次保存前备份 schema 3；检查时间、错误、最高验签版本和事务 ID 独立原子写入 `update-state.json`。启动显示后延迟 10 秒、自动检查间隔至少 24 小时，手动检查不受节流限制。
  - UpdateService 通过 Qt queued signals 驱动检查、下载、取消、验证和待安装状态；更新下载独立于视频队列，取消会关闭当前 response。自动失败只写状态和日志，手动失败提供中文“重试／复制错误报告／关闭”。
  - 设置页新增稳定通道、自动检查、手动检查与状态；发现更新使用可关闭的非模态提示。能力严格分为 CHECK_ONLY / DOWNLOAD_AND_VERIFY / AUTO_INSTALL，只有正式 frozen、非 validation-only、含预置信任根且含外部 updater 的构建可显示“退出并更新”。
  - 忙时默认继续当前任务；只有用户明确选择“取消任务并更新”才停止解析/视频/缩略图等后台任务，等待清理与落库后从安装目录外启动 updater。完整验签包可跨重启保留，但恢复时重新验签并复核长度和 SHA256。
  - 完整回归：241 passed（19.42 秒，跨重启验证补充后待 Phase 10 总回归更新）。浅色/深色真实设置页截图 `.tool-stage/v040-phase9e-settings-light.png`、`v040-phase9e-settings-dark.png` 已目视验证。
