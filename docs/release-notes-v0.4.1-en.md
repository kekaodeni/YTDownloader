# YTDownloader v0.4.1

This release carries the verified Qt Quick / QML desktop interface for downloads, history, settings, dialogs, and thumbnails.

Typography fallback, menu highlighting, hover behavior, scrolling, and view lifecycle handling are included in the verified build.

MKV supports embedded JPEG and PNG covers, including the WebM-to-MKV cover workflow.

Cover replacement preserves subtitles, chapters, and other attachments; invalid or corrupted covers do not replace the original media.

The release package includes a signed update manifest and a SHA-256 checksum sidecar.

Windows Authenticode code signing and an installer are not included.

Windows Explorer display of embedded MKV covers depends on a compatible thumbnail provider and is not guaranteed on every Windows installation.
