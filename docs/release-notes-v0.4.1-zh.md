# YTDownloader v0.4.1

本版本延续已验证的 Qt Quick / QML 桌面界面，覆盖下载、历史记录、设置、对话框和缩略图页面。

已验证版本包含字体回退、菜单高亮、鼠标悬停、滚动和界面生命周期处理。

MKV 支持内嵌 JPEG 和 PNG 封面，并支持 WebM 转 MKV 后写入封面的流程。

替换封面时保留字幕、章节和其他附件；非法或损坏的封面不会替换原媒体。

本发布包包含签名更新清单和 SHA-256 校验文件。

本版本不包含 Windows Authenticode 代码签名或安装器。

Windows Explorer 是否显示 MKV 内嵌封面取决于兼容的缩略图提供器，不能保证所有 Windows 系统都原生显示。
